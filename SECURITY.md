# Security Policy

## Supported Versions

jsEasy is currently pre-1.0. Security fixes are applied to the latest released version.

## Intended Use

jsEasy is intended for legitimate scraping, testing, research, and data extraction where the user is authorized to access the content.

The project does not accept features intended to bypass:

- CAPTCHAs;
- login walls;
- payment walls;
- rate limits;
- access-control systems;
- anti-abuse protections.

## Reporting A Vulnerability

If you find a vulnerability, please open a private security advisory on GitHub once the repository is available, or contact the maintainer through the published package metadata.

Please include:

- affected version;
- reproduction steps;
- impact;
- suggested fix, if known.
